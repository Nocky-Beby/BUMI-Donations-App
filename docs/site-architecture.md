## 2. Contenu principal des pages

### Accueil
Met en avant :
- la mission de BUMI ;
- la centralisation de la gestion des dons ;
- la transparence et la traçabilité ;
- les besoins prioritaires ;
- les témoignages et l’impact.

### À propos
Présente :
- le contexte de l’orphelinat ;
- la mission sociale ;
- la valeur ajoutée de la plateforme.

### Nos besoins
Affiche :
- les besoins en temps réel ;
- les catégories ;
- les niveaux d’urgence ;
- la progression de couverture.

### Comment faire un don
Explique :
- l’inscription ;
- le choix du type de don ;
- l’enregistrement ;
- le suivi d’affectation.

### Impact
Montre :
- les résultats concrets ;
- les rapports ;
- les témoignages.

### Contact
Permet :
- de contacter l’équipe ;
- de proposer un partenariat ;
- d’obtenir des informations.

### FAQ
Répond aux questions fréquentes sur :
- les dons ;
- la transparence ;
- les rôles ;
- l’évolution du système.

## 3. Expérience utilisateur claire par acteur

### Donateur
Flux :
1. consulter les besoins ;
2. créer un compte ;
3. se connecter ;
4. enregistrer un don ;
5. suivre l’affectation ;
6. consulter l’historique.

### Administrateur
Flux :
1. accéder au tableau de bord global ;
2. gérer donateurs et partenaires ;
3. gérer les besoins ;
4. superviser les distributions ;
5. générer les rapports.

### Responsable
Flux :
1. mettre à jour les besoins ;
2. suivre les dons reçus ;
3. préparer les distributions ;
4. consulter les rapports opérationnels.

### Partenaire
Flux :
1. consulter les besoins ;
2. visualiser les contributions ;
3. suivre l’impact ;
4. accéder aux rapports associés.
